Why must the "snake charmer" always be depicted as a human playing music to a snake? Snakes can be charming too! Why, I'll prove it. Behold, my tunes!

In this project, we took a song and played it through the buzzer on LilyPad boards. When a button (A9 pin) is pressed, the song plays and stops when the button is released. To code the notes, I assigned each note the right frequency (which I found [here](https://electricalelibrary.com/en/2018/08/26/arduino-tutorial-part-9-music-and-keypad/) on Electricale Library). The song I chose was "Creator" by Lena Raine, one of my favorite Minecraft OSTs (original soundtracks). The song is long and complicated so I only managed to code the first minute of it. I worked through this assignment by listening to "Creator" on Spotify while using a virtual piano in another tab to help me isolate the notes. 

One of the first things I tried to do was play multiple notes by switching between them quickly (like how we turned the LEDs to different brightnesses) but the buzzer couldn't keep up with that. So instead I played around with the tempo to give the illusion that multiple instruments were playing at the same time. I split the song into ten chunks, each with an if statement checking to see if the button was pressed before continuing the song.



I made the variable "TEMPO" serve as my delay value between the notes, and the speed of the song depends on what value the tempo is set to. I imagine TEMPO as representing the quarter notes. If I need a longer or shorter note, I multiply TEMPO by my desired length.
I also made a new variable "section" to help keep track of which chunk was supposed to play. This helped me test the chunks individually, and it insured that when the button was pressed, the song would always start at the beginning. Each section also ends with the line turning the buzzer off in the "else" section so the notes don't keep playing if the button is deactivated.
